# MPStorys Resources

[MPStorys](https://mpstorys.com) is an independent, fan-made community hub for MapleStory players.

It brings together useful information and resources in one place:

- MapleStory news and official announcements
- Upcoming updates and limited-time events
- Practical gameplay guides and strategies
- Player tools, calculators, and simulators
- Rankings and progress information
- Community-curated wiki resources

## Game Coverage

MPStorys covers multiple games across the MapleStory universe:

- MapleStory
- MapleStory Classic
- MapleStory M
- MapleStory Worlds
- MapleStory N
- MapleStory Idle

Information is organized by game series and region so players can find content relevant to the version they play.
